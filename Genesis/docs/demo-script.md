# Demo recording script - draft

Target recording length: **150 seconds**. This is a script, not a recorded video or evidence of release. Rehearse against actual stored results and keep the final recording below 180 seconds.

Do not record a success journey until its genuine investigation, manual grounding, human feedback, A5, explicit freeze and held-out comparison exist. While those gates are unresolved, a rehearsal must show current unavailable/disabled states and say so. Display fixtures and fault doubles must never become submission evidence. Keep tokens, credentials, private account information and held-out case identities out of the recording.

| Time | Screen / action | Narration and evidence requirement |
|---|---|---|
| 0:00-0:15 | Signed-out investigation workspace | "AML Insight puts source evidence, bounded AI investigation and accountable analyst review in one workspace." Explain the synthetic-data and recommendation-only scope. |
| 0:15-0:35 | Select a case; inspect evidence and detector signals | Explain the queue hint without calling it a completed triage priority. Show the frozen deterministic source and why its evidence needs review. |
| 0:35-1:05 | Authorized real parent run and private brief | Show actual sealed A1/A2/A3/A4/A0 states, stored run ID and grounded citations. Refresh explicitly. Do not imply a pre-recorded result finished instantly. If absent, say the genuine investigation remains pending and show the refusal honestly. |
| 1:05-1:30 | Selected-alert analyst review and history | The human analyst explains their own verdict and notes against the real completed run. Do not script or manufacture their judgment. Show history only if it was genuinely submitted. |
| 1:30-1:55 | Evolution snapshot and stored A5 | Show actual sample sizes, snapshot provenance and A5's real sufficiency decision. INSUFFICIENT_EVIDENCE is valid. Absent evidence must be described as pending. |
| 1:55-2:15 | Explicit candidate freeze and held-out result | Use an actual operator-frozen candidate and its single stored comparison. State if it was frozen despite insufficient review evidence. Show aggregate outcomes; do not expose private labels or tune from held-out results. |
| 2:15-2:30 | Usage, architecture and release links | Show actual usage with unknown costs left unknown, public/private boundaries and verified deployed links. Describe measured outcomes only. End with the recommendation-only scope and current limitation. |

Before recording, verify the release revision, public demo/repository links in a signed-out browser, private output authorization and final deck claims. After recording, measure the video file's duration; a 150-second script does not establish the produced video's length. Store actual duration and URLs only after validation.
