Controls that make failure visible

Bound requests. Preserve uncertainty.

Before a request

  • Recheck mode, credits, expiry, switch, cap and worker lease.
  • Reserve each attempt atomically.
  • Freeze model, prompts and retry limits in immutable versions.

After a request

  • Seal the attempt before the next leg.
  • Permit one retry only for a known short transient rejection.
  • Keep unknown provider outcomes, usage and cost visibly unknown.

Input / generated-token caps: A2 4096 / 1536; A3 2048 / 768; A4 4096 / 2048; A5 8192 / 3072. Cloud daily maximum: 120 attempts, including retries. New UTC days start disabled.
