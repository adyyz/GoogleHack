# Brief description - draft

AML Insight is a recommendation-only investigation prototype for AML analysts reviewing synthetic transaction data. It combines nine deterministic alert rules with a bounded Gemini workflow for risk explanations, categorization and evidence-linked investigation briefs. Analysts retain the final decision, while immutable configurations, attempt accounting and review history make the process traceable. A separate Evolution workflow analyzes genuine feedback and requires an explicit candidate freeze before a stored held-out comparison. Public visitors see frozen synthetic evidence and aggregate usage; model narratives and reviews remain private. The current implementation is locally verified. A genuine completed investigation, human evaluation evidence and the deployed Google Cloud demo remain pending.
